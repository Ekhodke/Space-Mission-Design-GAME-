  - The game is a full-screen, first-person-style 3D salvage world set in humanity's final hours on a dying Earth.
  - Use **WASD** to walk, **Shift** to sprint, and point at a wooden supply crate or ship hardware and press **E** (or click) to inspect it.
  - Recover components from scattered crates. Recovered hardware appears in the field-cargo hotbar; drag a cargo slot onto the world/ship to install it. Installed ship parts can be inspected and removed.
  - Click **Ship systems** to open the complete control sidebar: mission objective, difficulty, live resource dashboard, hardware catalog, orbit and launch choices, crew roles, interactive flight-console tasks, and mission simulation.
  - Click a world object to open its function/settings panel. Hardware mass is visible before installation; its real mass is used in the spacecraft resource calculations.
  - Click **Pause** to pause the view. Press **Esc** to release mouse look; click the world again to resume looking around.

The world uses Three.js from jsDelivr, so an internet connection is required. This is a front-end learning simulation, not a networked multiplayer game or flight-certified engineering tool.
